# Open Source Extraction Notes

This repository was extracted from a local research workflow with a conservative public-safety boundary.

Included:

- Source-pack JSON schema.
- Public-source discovery logic for JPX pages and company IR search candidates.
- Optional J-Quants Free listed-info retrieval using an environment variable.
- Minimal tests and public documentation.

Excluded:

- `.env` files and credentials.
- Downloaded filings, cache files, generated reports, and local analysis outputs.
- Upstream third-party plugin material.
- Private notes, logs, screenshots, images, spreadsheets, PDFs, and customer/site-operation assets.

The first public version is intentionally small so the repository can be reviewed, maintained, and extended without mixing private research artifacts into the OSS history.
